# 공개/배포 안전 정책

이 저장소는 모딩 기술과 소스 공개를 목적으로 하며 게임 콘텐츠 배포를 목적으로
하지 않습니다.

저장소에 포함하지 않는 항목:

- 게임 실행 파일 및 게임 DLL
- `GameAssembly.dll`, `UnityPlayer.dll`, `global-metadata.dat`
- `Assembly-CSharp.dll`, Unity/TextMeshPro 게임 참조 DLL
- 게임 데이터/에셋/음성/이미지/시나리오 덤프
- 일본어 원문 ↔ 한국어 번역 매핑 파일
- `_AutoGeneratedTranslations.txt`
- 개인 `AutoTranslatorConfig.ini`
- 로그, 덤프, API 키, 토큰, 개인 절대 경로

GitHub Release에 third-party 바이너리를 추가하는 경우 반드시 해당 upstream
라이선스와 대응 소스/패치 제공 조건을 다시 확인합니다. 특히 수정된
Il2CppInterop 바이너리는 `LGPL-3.0-only` 조건을 따르므로 대응 소스,
변경 고지 및 라이선스 전문 제공 여부를 Release 전에 다시 검증합니다.
