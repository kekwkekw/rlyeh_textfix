# Il2CppInterop compatibility patch

This directory records the single Il2CppInterop modification used by the tested
rlyehshoujotaix_cl environment. Apply `InjectorHelpers.patch` to the exact
upstream revision documented in `UPSTREAM.md`, then build Il2CppInterop using
its upstream build instructions.
