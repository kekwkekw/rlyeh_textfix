`RlyehTextFix` is a BepInEx 6 IL2CPP plugin developed for the DMM Windows build
of **邪神戦記ルルイエ少女隊 / rlyehshoujotaix_cl**. The repository documents a
working Unity 6000.3.5f2 modding setup and the compatibility patches needed to
run XUnity.AutoTranslator 5.6.1 in the tested environment.

## What it fixes

- Korean story text being cut off before the translated sentence is complete
- proportional typewriter display using the translated Korean text length
- consistent TMP overlay font rendering for story text and speaker names
- missed first lines after cutscene/scene transitions
- visible UTAGE control tags while preserving timing behavior
- translation fragmentation caused by display-only TMP rich-text tags

The RichText integration patches XUnity's parser externally from RlyehTextFix;
the original game string remains intact while selected display tags are ignored
for translation context.

## Verified environment

- Unity 6000.3.5f2
- BepInEx 6.0.0-be.785 (`6abdba47eeebe08552282e7a58ef0f4a9ab60b62`)
- XUnity.AutoTranslator 5.6.1

- RlyehTextFix 1.1.0

See [`docs/VERIFIED_ENVIRONMENT.md`](docs/VERIFIED_ENVIRONMENT.md) for the

## Build

The repository does not contain game binaries or generated game interop
assemblies. Build against your own local installation:

```powershell
.\build\Build-RlyehTextFix.ps1 -GameDir "C:\Games\rlyehshoujotaix_cl"
```

See [`docs/BUILDING_KO.md`](docs/BUILDING_KO.md).

## Compatibility patches

Two upstream components required compatibility changes in the verified setup:

1. **XUnity.AutoTranslator v5.6.1** — use the non-generic
   `GameObject.AddComponent(Il2CppSystem.Type)` path in `PluginLoader.cs`.
2. **Il2CppInterop v1.5.3** — disable
   `GetFieldDefaultValueHook.ApplyHook()` in `InjectorHelpers.Setup()`.

Exact upstream revisions and patches are under `patches/`.

## Translation files

This public repository intentionally does **not** include:

- Korean translation mappings
- game-text translation regexes tied to original game sentences
- `_AutoGeneratedTranslations.txt`
- scenario dumps or other game text datasets

Community translation packages may be distributed separately from this source
repository.
